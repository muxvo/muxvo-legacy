### 2. 产品定位
- **目标用户**：使用 AI CLI 工具（Claude Code、Codex、Gemini CLI）的开发者
- **核心痛点**：需要同时管理多个 AI CLI 终端实例，在不同项目和工具间快速切换
- **产品价值**：提供多终端平铺/聚焦/列表三种视图，统一管理终端生命周期
- **使用场景**：日常开发中同时运行多个 AI CLI 会话

### 3. 功能范围（全部 P0，重写）
- 终端生命周期管理（创建/关闭/状态跟踪）
- 三种视图模式（Tiling / Focused / List）
- XTerm 渲染与交互
- 视觉效果与动画
- 新手引导 Tour
- 设置与快捷键

### 4. 业务规则
- 最大终端数：20
- 进程状态：10 种
- 输出 buffer：64KB 滚动
- 关闭超时：5 秒优雅关闭
- Bell 冷却：3 秒
- 状态推送去抖：50ms

### 5. 数据需求
- onboarding.complete / onboarding.step 埋点
- 终端使用统计（已有 analytics 模块）
