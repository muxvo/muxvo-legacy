# A3. 用户画像

> 本附录细化 Muxvo 的核心用户画像，便于各模块的 §2 目标用户章节引用。

---

## 画像 1：CLI 重度用户（主流用户，60%）

**代号**：P1

### 基本特征
- 职业：全栈工程师 / 后端工程师 / DevOps / AI 产品开发者
- 每天使用 Claude Code 工作 4 小时以上
- 同时管理 3-10 个终端和 2-5 个项目
- 习惯键盘操作胜过鼠标
- 对响应速度敏感

### 典型需求
- 快速在多个终端之间切换而不丢上下文
- 看到哪些终端在等待我的输入
- 想查之前和 Claude 讨论过的某个决策
- 不想每次都重新打字，希望有草稿保留

### 设计侧重
- 为 P1 优化：快捷键齐备、状态点显眼、搜索强力
- P1 会被什么劝退：启动慢、白屏、状态点延迟、搜索不准

### 相关模块
全部。核心痛点在 M01 / M02 / M03 / M04 / M08 / M09。

---

## 画像 2：项目切换者（高频场景用户，20%）

**代号**：P2

### 基本特征
- 职业：独立开发者 / 自由职业 / 咨询师
- 工作在多个代码仓库之间高频切换
- 需要快速定位某个项目的对话历史

### 典型需求
- 按项目分组查看聊天记录
- 工作区快照（保存"A 项目的布局"一键恢复）
- 文件面板快速查看项目结构

### 设计侧重
- 为 P2 优化：项目分组、工作区快照、多源支持
- P2 会被什么劝退：项目分组混乱、无法批量切换

### 相关模块
M08 CHAT_BROWSE、M14 ONBOARD_PREFS（工作区快照）、M11 FILE_PANEL

---

## 画像 3：Skill 作者（垂直深度用户，10%）

**代号**：P3

### 基本特征
- 职业：提示词工程师 / AI 内容创作者 / 教育从业者
- 自己开发 Claude Skill 和 MCP Server
- 需要在"编写 Skill"和"测试 Skill"之间频繁切换

### 典型需求
- 浏览已安装的 Skills / MCP / Hooks / Plugins
- 编辑 Skill 的 Markdown 文件（WYSIWYG 或源码）
- 开关某个 Hook 测试副作用

### 设计侧重
- 为 P3 优化：M13 CONFIG_MGMT 的编辑体验、启停即时生效
- P3 会被什么劝退：无法编辑、启停没反馈、冲突提示不清

### 相关模块
M13 CONFIG_MGMT、M12 FILE_VIEWER（Markdown 编辑）

---

## 画像 4：新手（首次使用，10%）

**代号**：P4

### 基本特征
- 职业：不限，可能首次接触 AI CLI 工具
- 之前未使用过 Claude Code 或仅在命令行使用
- 对"终端"有模糊概念但不确定如何高效使用

### 典型需求
- 一步步引导告诉我怎么开始
- 最好有个 Demo 让我看到"正确的样子"
- 出错时知道接下来要做什么

### 设计侧重
- 为 P4 优化：M14 ONBOARD_PREFS 的 Tour 和欢迎页、CLI 工具检测、首次使用默认偏好足够保守
- P4 会被什么劝退：一打开就是空界面、错误文案晦涩、无引导

### 相关模块
M14 ONBOARD_PREFS（首次引导）、M15 APP_RELIABILITY（错误文案可读）
