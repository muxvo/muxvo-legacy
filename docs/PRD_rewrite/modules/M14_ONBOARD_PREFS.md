# M14 ONBOARD_PREFS – 首次引导与偏好设置 PRD

> 版本 v1.0 · 适用 Muxvo Rust 重构 · 行数预算 650 行 ±15%

## 1. 模块定位

- 一句话：让新用户 60 秒内学会 Muxvo 的四件事，让老用户一次性把工作台调成自己喜欢的样子。
- 没有本模块，用户第一次打开 Muxvo 会面对一个空白主界面，不知道按钮在哪、不知道能不能改字号主题；老用户每次重启都要重新摆位置，修改了的选项不会被记住。
- 与相邻模块分界：
  - 欢迎页、新手导览、设置面板、工作区快照、更新日志属于本模块 / 终端创建与销毁属于 [M01-TERM_LIFECYCLE]
  - "双击切到聚焦模式"的开关项属于本模块 / 聚焦模式本身的表现属于 [M03-TERM_FOCUS]
  - "显示隐藏文件"的开关项属于本模块 / 文件面板如何渲染属于 [M11-FILE_PANEL]

## 2. 目标用户与场景

**主要用户画像**
- **新手**：第一次打开 Muxvo，不清楚它是干什么的，需要一步一步被告知"第一件事做什么"。
- **老用户**：已经熟悉主界面，希望把字号、主题、启动终端数、默认路径调成自己惯用的样子，并保存一组"常用工作区"一键恢复。
- **跨设备使用者**：在公司用亮色、家里用暗色，要求设置改动立刻生效、重启后还在。

**Top3 使用场景**
1. *第一次启动*：用户下载安装后第一次双击图标。看到欢迎卡片与四步导览，照着做完就拥有了一个能用的终端，并且知道怎么聚焦、怎么重命名、怎么开文件面板。
2. *调整个人偏好*：老用户按下齿轮按钮进入设置面板，把启动终端数从 1 改成 3，把主题从暗色切到亮色，把默认新建路径指到常用项目目录。关闭设置后立刻看到主题变化，下次启动自动打开 3 个终端。
3. *保存工作区快照*：用户围绕一个项目开了 5 个终端并各自命名，把它们作为一个工作区保存下来；下次换项目前点击"保存为工作区"，下次想回来时从工作区管理器一键恢复。

**使用频率**：欢迎页与导览仅一次；设置面板偶尔；工作区保存/恢复每周几次；更新日志每次升级一次。

## 5. 详细需求条目

### REQ-ONBOARD_PREFS-001 首次启动欢迎卡片

**触发方式**：首次安装后双击应用图标并等待主界面完全加载。
**前置条件**：用户从未完成过导览。
**正常流程**：
  1. 用户打开 Muxvo
  2. 主界面出现 1.5 秒后，屏幕中央浮出一张卡片
  3. 卡片上半部是标题"欢迎使用 Muxvo"与一段两行的产品简介："Muxvo 是为 AI CLI 工具打造的桌面工作台。接下来的快速导览将帮助你了解核心功能。"
  4. 卡片底部两个按钮："开始导览"（主色）与"跳过，稍后再看"（次色）
**用户看到的反馈**：卡片带有淡入动画；背景变暗遮罩。
**结束状态**：用户点击其中一个按钮后卡片消失。
**异常情况**：如果用户之前完成或跳过过导览，本卡片不再出现。
**相关**：REQ-ONBOARD_PREFS-002、REQ-ONBOARD_PREFS-030

### REQ-ONBOARD_PREFS-002 四步交互式导览

**触发方式**：在欢迎卡片点击"开始导览"，或在设置面板"帮助"区点击"新手引导"。
**前置条件**：主界面已加载。
**正常流程**：
  1. **第一步**：屏幕变暗，右下角"+"按钮被高亮抠出，气泡标题"新建终端"，正文"点击 + 按钮，创建你的第一个终端吧！"。用户必须真的点 + 才能推进。
  2. **第二步**：一个终端出现后自动推进到"聚焦终端"，高亮该终端的蓝色最大化按钮，气泡写"试试点击这个蓝色按钮，把终端最大化为聚焦模式！"。用户点了最大化才能推进。
  3. **第三步**："重命名终端"，高亮终端标题位置，文案"点击这里为终端起个名字，方便在多个终端间快速识别。"。用户输入任意名字后推进。
  4. **第四步**："打开文件"，高亮终端右上角"文件"按钮，文案"点击'文件'按钮，打开当前目录的文件浏览器！"。用户点了文件按钮后导览完成。
**用户看到的反馈**：气泡右上角有关闭按钮；进度显示"当前步/总步"；每步完成后 0.5 秒延迟再切到下一步。
**结束状态**：第四步结束时气泡消失，屏幕中央浮出祝贺条，文件面板保持打开。
**异常情况**：
  - 用户跳过：下次启动直接进入主界面。
  - 用户在某一步长时间不动作：导览不会自行前进，也不会消失，用户可随时关闭。
**相关**：[M01-REQ-001]、[M03-REQ-001]、[M11-REQ-001]

### REQ-ONBOARD_PREFS-003 导览中途关闭

**触发方式**：任意一步的气泡右上角关闭按钮。
**前置条件**：导览正在进行。
**正常流程**：用户点关闭 → 气泡与遮罩一起消失 → 已建立的终端保留 → 下次启动不再弹出欢迎页与导览。
**用户看到的反馈**：遮罩淡出动画。
**结束状态**：主界面恢复正常。
**异常情况**：无。
**相关**：REQ-ONBOARD_PREFS-030

### REQ-ONBOARD_PREFS-004 完成导览祝贺提示

**触发方式**：第四步动作被检测到完成。
**正常流程**：屏幕中央浮出一条居中提示条，深色半透明背景。
**用户看到的反馈**：文案"恭喜！你已完成新手引导，开始享受 Muxvo 吧！"；出现 3 秒后自动淡出。
**结束状态**：提示条消失，用户回到主界面。
**异常情况**：用户是"跳过"而非"完成"时不显示祝贺条。
**相关**：REQ-ONBOARD_PREFS-002

### REQ-ONBOARD_PREFS-005 再次观看导览

**触发方式**：设置面板 → 帮助区 → 点击"新手引导"按钮。
**正常流程**：设置面板先关闭，0.1 秒后导览从第一步重放。
**用户看到的反馈**：与首次启动完全一致。
**结束状态**：同 REQ-ONBOARD_PREFS-002。
**相关**：REQ-ONBOARD_PREFS-002

### REQ-ONBOARD_PREFS-006 设置面板入口

**触发方式**：顶部导航栏齿轮图标点击。
**前置条件**：无。
**正常流程**：点击 → 设置面板以浮层形式滑入 → 背景遮罩变暗 → ESC 键或点击遮罩关闭。
**结束状态**：关闭时面板平滑消失，主界面恢复可点击。
**相关**：REQ-ONBOARD_PREFS-007

### REQ-ONBOARD_PREFS-007 设置面板五章节布局

**触发方式**：打开设置面板。
**正常流程**：面板从上到下依次呈现五个区块标题："通用 / 外观 / 快捷键 / 语言 / 帮助"。每个区块下列出若干行，每行左侧是标题+说明文字，右侧是控件。
**用户看到的反馈**：区块标题有分隔线；行之间有淡灰色分隔。
**结束状态**：用户滚动即可看到所有项。
**异常情况**：Dock 角标区块只在 macOS 上显示。
**相关**：REQ-ONBOARD_PREFS-008 至 REQ-ONBOARD_PREFS-020

### REQ-ONBOARD_PREFS-008 启动终端数量

**触发方式**：设置面板 → 通用 → "启动终端数量"行。
**默认值**：1。
**用户如何修改**：行右侧一个"− 数字 +"步进器，点击 − 或 + 调整。
**生效时机**：下次重启 Muxvo 时自动创建该数量个终端；当前会话不变。
**范围**：1 到 20；到达边界时对应按钮变灰不可点。
**重置行为**：全部偏好重置后回到 1。
**用户看到的反馈**：数字立刻刷新；副文案"每次打开 Muxvo 自动创建的终端数量"。
**相关**：[M01-REQ-001]

### REQ-ONBOARD_PREFS-009 双击聚焦开关

**触发方式**：设置面板 → 通用 → "双击聚焦"。
**默认值**：关闭。
**用户如何修改**：右侧两段式按钮"启用 / 关闭"。
**生效时机**：立即，主界面双击终端时切换到聚焦模式。
**副文案**："双击终端切换到全屏聚焦模式"。
**重置行为**：回到关闭。
**相关**：[M03-REQ-001]

### REQ-ONBOARD_PREFS-010 默认终端工作路径

**触发方式**：设置面板 → 通用 → "终端默认路径"。
**默认值**：空（新终端打开在用户主目录）。
**用户如何修改**：右侧显示当前路径，或占位符"默认为用户主目录"；点击"浏览"按钮弹出系统目录选择器；选完一个目录后路径立刻显示在设置面板里；已设置时额外出现"清除"按钮。
**生效时机**：立即，下次新建终端即在该路径打开。
**重置行为**：清除后回到空，回到用户主目录。
**异常情况**：用户选择的目录不存在或无权限时，新终端会退回主目录并在下一次打开时不再重试。
**相关**：[M01-REQ-005]

### REQ-ONBOARD_PREFS-011 Dock 角标通知模式

**触发方式**：设置面板 → 通用 → "Dock 角标通知"（仅 macOS 可见）。
**默认值**：关闭。
**用户如何修改**：三段式按钮"关闭 / 实时 / 定时"。
**生效时机**：立即。
**三种模式的差异**：
  - **关闭**：应用图标永远不显示数字角标。
  - **实时**：任何一个终端进入等待输入状态的瞬间，应用图标右上角出现数字角标，数字等于当前等待中的终端总数。
  - **定时**：按下面的"检查间隔"周期性检查，到点再刷新角标数字；适合不想被频繁打扰的用户。
**副文案**："终端等待输入时在 Dock 图标上显示数字角标"。
**重置行为**：回到关闭。
**相关**：[M04-REQ-003]

### REQ-ONBOARD_PREFS-012 Dock 角标定时间隔

**触发方式**：仅当上一项选了"定时"时，下方多出一行"检查间隔"。
**默认值**：1 分钟。
**用户如何修改**：步进器或输入框，支持直接敲数字；失焦或按回车后生效。
**范围**：最小 1，没有上限硬约束；输入非法内容或空时自动回到 1。
**单位**：分钟，显示在输入框右侧。
**重置行为**：回到 1。
**相关**：REQ-ONBOARD_PREFS-011

### REQ-ONBOARD_PREFS-014 全局缩放

**触发方式**：键盘快捷键 ⌘+（放大）/ ⌘-（缩小）/ ⌘0（复位）。
**默认值**：100%（级别 0）。
**范围**：50% 到 200%，每步 10%，共 -5 到 +10 十六档。
**生效时机**：按键即时生效，整个主界面包括终端、文件面板、设置面板同步缩放；松手后约 0.5 秒把新的缩放级别保存下来。
**重置行为**：按 ⌘0 或重置偏好回到 100%。
**用户看到的反馈**：画面整体放大缩小。
**注意**：此项与"终端字号"、"全局基准字号"是三个独立维度——缩放影响的是整套画面的像素倍率；终端字号影响的只是终端里字符的大小；全局基准字号影响的是主界面非终端区的文字基准尺寸。

## 6. 主要用户旅程

### Journey 1：第一次打开 Muxvo（新手视角）

1. **你**第一次双击 Muxvo 图标 → 窗口弹出，出现一个空的主界面
   → **所见**：主界面最初有一个淡灰色的"+"大按钮
   → **感受**：不知道该干啥
2. 1.5 秒后 → **所见**：中央浮出欢迎卡片，写着"欢迎使用 Muxvo"
   → **感受**：噢，它在告诉我下一步
3. **你**点"开始导览" → **所见**：屏幕变暗，右下角"+"被挖空高亮
   → **感受**：我知道要点哪个按钮了
4. **你**点"+" → **所见**：第一个终端出现，气泡立刻跳到"聚焦终端"
   → **感受**：原来它会自动推进
5. **你**点蓝色最大化按钮 → **所见**：终端变成全屏聚焦模式，气泡推进到"重命名终端"
6. **你**给终端起个名字 → **所见**：气泡推进到"打开文件"
7. **你**点"文件"按钮 → **所见**：文件面板滑出，中央浮出"恭喜！你已完成新手引导"
   → **感受**：四步完成了，我现在知道 Muxvo 能干嘛
8. 3 秒后祝贺条消失 → **你**回到主界面正常使用

### Journey 2：老用户调偏好（高频路径）

1. **你**打开 Muxvo → **所见**：主界面按上次状态恢复
2. **你**觉得白天用亮色好看 → 点顶部齿轮图标
   → **所见**：设置面板从右侧滑入，覆盖主界面
3. **你**滚动到"外观"区 → 点"亮色"
   → **所见**：主界面瞬间由黑变白，设置面板本身也变白
4. **你**切到"通用"区 → 把"启动终端数量"从 1 调到 3
5. **你**点"终端默认路径"旁的"浏览"按钮 → 系统目录选择器弹出 → 选一个项目根目录
6. **你**按 ESC 关闭设置面板 → **所见**：主界面恢复，上面的改动已生效
7. **你**关闭 Muxvo → 明天再打开 → **所见**：亮色主题、3 个终端、都开在你选的项目目录里
   → **感受**：它记住了我的喜好

### Journey 3：快照加载失败恢复

1. **你**之前保存了一个名为"公司项目"的工作区，5 个终端 → 今天同事把其中一个目录删了
2. **你**打开 Muxvo → 点顶部工作区选择器 → 选"公司项目"
   → **所见**：确认对话框"加载工作区会关闭当前所有终端，是否继续？"
3. **你**点"继续" → **所见**：5 个终端逐个打开，其中一个标题仍是原名字但路径回到主目录
   → **感受**：一个不见的目录不会阻塞整个恢复
4. **你**删掉那个错位的终端，把"公司项目"用"管理工作区"删除后重新保存一次
   → **所见**：列表里只有正确的一条
5. 下次再载入时一切正常

### 7.2 各页关键区域

**欢迎卡片**
- 主区：标题 / 两行产品简介 / 主按钮"开始导览" / 次按钮"跳过，稍后再看"
- 浮层：覆盖全屏的半透明遮罩

**导览气泡**
- 顶栏：无
- 主区：高亮目标元素 + 箭头气泡 + 标题 + 描述 + 进度文字"当前/总数" + 右上角关闭
- 浮层：除目标元素外的屏幕部分被深色遮罩覆盖

**设置面板**
- 顶栏：齿轮图标 + "设置" + 右上角关闭 ×
- 主区：通用 / 外观 / 快捷键 / 语言 / 帮助五个区块，竖向滚动
- 每行：左侧标题 + 说明文字，右侧控件（步进器 / 两段按钮 / 三段按钮 / 路径显示 + 浏览）

**工作区管理器**
- 顶栏：标题"Manage Workspaces" + 关闭 ×
- 主区：一行一个工作区
- 空态：居中文字"No saved workspaces"

**更新内容弹窗**
- 顶栏：星型图标 + "更新内容" + 关闭 ×
- 主区：当前版本徽章 + 分区条目 + 历史版本折叠列表
- 底栏：单个"知道了"按钮

### 7.3 五态规格

**设置面板**

| 状态 | 用户看到什么 | 可做的动作 |
|---|---|---|
| 空态 | 不适用，偏好即使从未修改也有默认值显示 | — |
| 加载态 | 打开瞬间各控件显示默认值，约 100ms 后被已保存值覆盖 | 可直接操作，不会被打断 |
| 正常态 | 所有控件显示当前值，主题立刻变化 | 修改任何字段 |
| 错误态 | 某个值写入失败时该字段仍显示用户刚刚选的值，下次打开回到之前的已保存值 | 重新尝试修改 |
| 受限态 | 非 macOS 不显示 Dock 角标区块 | 其他区块正常可用 |

**工作区管理器**

| 状态 | 用户看到什么 | 可做的动作 |
|---|---|---|
| 空态 | 居中文字"No saved workspaces" | 关闭后先去主界面"保存为工作区" |
| 加载态 | 打开后几乎即时显示列表 | 直接操作 |
| 正常态 | 列表每行显示名称、"N 个终端"、删除按钮 | 点名称改名、点 × 删除 |
| 错误态 | 保存失败时改名被回滚，用户看到旧名 | 重试改名 |
| 受限态 | 不适用 | — |

**更新内容弹窗**

| 状态 | 用户看到什么 | 可做的动作 |
|---|---|---|
| 空态 | "v<版本> 暂无更新说明" | 关闭 |
| 加载态 | 打开后瞬间显示当前版本，历史条目逐条出现 | 关闭 |
| 正常态 | 分区标题 + 条目列表 + 历史版本折叠 | 点版本展开、点"知道了"关闭 |
| 错误态 | 无法读取更新内容时，中央显示空态文字 | 关闭 |
| 受限态 | 不适用 | — |

## 8. 状态与交互规则

### 8.1 可见状态清单

- 欢迎卡片是否显示
- 导览是否进行中、当前是第几步、目标元素是否已高亮
- 设置面板是否打开
- 工作区管理器是否打开、是否有某条正处于改名编辑态
- 更新内容弹窗是否打开、哪些历史版本处于展开态
- 各偏好的当前值是否为"修改中但尚未生效"

### 8.2 状态切换触发

- 用户首次启动 → 1.5 秒后看到欢迎卡片
- 用户点"开始导览" → 卡片消失并进入导览第一步
- 用户在导览中点关闭 → 导览结束，下次启动直接进主界面
- 用户在第一步点 + 按钮且终端数量增加 → 0.5 秒后推进到第二步
- 用户把主题切换 → 主界面立即重绘
- 用户改语言 → 整套界面文案立即重绘
- 用户调启动终端数 → 面板数字更新，下次启动生效
- 用户在工作区管理器点名称 → 进入改名编辑态
- 用户在改名态按回车 → 改名完成；按 ESC → 回滚
- 用户升级后首次打开且距上次启动超过一次版本号变更 → 2 秒后弹出更新内容

### 8.3 快捷键与手势

| 按键/手势 | 作用 | 前置条件 |
|---|---|---|
| ESC | 关闭当前最上层浮层（设置面板 / 工作区管理器 / 更新弹窗） | 浮层已打开 |
| 点击遮罩 | 同上 | 同上 |
| ⌘+ | 全局放大 10% | 有焦点 |
| ⌘- | 全局缩小 10% | 有焦点 |
| ⌘0 | 全局缩放复位 100% | 有焦点 |
| 回车 | 工作区管理器改名时提交 | 处于改名编辑态 |
| ESC | 工作区管理器改名时回滚 | 处于改名编辑态 |

### 8.4 多窗口行为

- 当前版本一次只运行一个主窗口。若用户同时打开多个窗口，偏好以最后一次保存的那次为准，其他窗口下次启动时看到最新值。

## 9. 边界、限制与异常

**数量限制**
- 启动终端数量：1 到 20
- 工作区快照：最多 10 个
- 缩放级别：-5 到 +10（50% 到 200%）
- Dock 角标定时间隔：最小 1 分钟
- 导览步骤：固定 4 步

**明确不支持**
- 不支持把设置面板内嵌在主界面（必须以浮层方式出现）
- 不支持导入/导出偏好文件
- 不支持为不同工作区设置不同偏好
- 不支持把导览做成非阻塞式（用户必须关闭才能继续其他操作）
- 不支持用户自定义主题配色（只能在预设里选）
- 不支持把"更新内容"弹窗设置为永不弹出
- 不支持多语言以外的语言（当前仅中/英）
- 不支持快捷键重映射

**错误提示文案**
> 工作区上限："已达到 10 个上限，请先删除一个再保存"
> 检查更新失败："检查失败"（红色）
> 已是最新："已是最新版本"
> 更新条目缺失："v<版本> 暂无更新说明"

**数据丢失风险与保障**
- 用户改完偏好后应用异常退出：最后一次修改有可能未写入；下次启动会回到上一次成功保存的值。
- 工作区快照被覆盖：改名和删除是立即生效的，没有撤销；用户必须谨慎。
- 更新日志读取失败：显示空态而非报错，不影响用户使用。

## 10. 明确不做的事（Out of Scope）

1. **云端偏好同步** — 为什么不做：首版聚焦本机体验；什么时候再考虑：引入账号中心后。
2. **偏好导入导出 JSON 文件** — 为什么不做：绝大多数用户不需要；什么时候再考虑：有企业部署需求时。
3. **每工作区独立偏好** — 为什么不做：交互复杂度过高；什么时候再考虑：用户明确反馈后。
4. **快捷键重映射 UI** — 为什么不做：首版保持单一方案降低学习成本；什么时候再考虑：键盘流用户反馈。
5. **自定义主题配色** — 为什么不做：美术一致性优先；什么时候再考虑：市场有明确诉求。
6. **多语言扩展到中英以外** — 为什么不做：用户基数未验证；什么时候再考虑：海外用户占比提升后。
7. **引导超过 4 步** — 为什么不做：超过 4 步的转化率显著下滑；什么时候再考虑：有新核心功能需要前置教学时。
8. **强制弹出"更新内容"每次重启都展示** — 为什么不做：打扰用户；什么时候再考虑：永远不考虑。
9. **在缺失 CLI 工具时弹出安装向导** — 为什么不做：Muxvo 定位为工作台而非安装器；什么时候再考虑：用户调研发现新手普遍被卡住。
