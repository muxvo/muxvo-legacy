# M08 CHAT_BROWSE – 聊天历史浏览 PRD

> 版本 v1.0 · 适用 Muxvo Rust 重构 · 行数预算 467-632 行

## 1. 模块定位

- **一句话**：让用户在一个安静的三栏界面里翻看自己之前和 Claude Code、Codex 聊过的所有内容，并能把任何一段旧对话重新打开到终端里继续聊。
- **不用它会怎样**：用户想回头看上周让 AI 帮忙改过的某段代码、想确认自己到底让 AI 做过什么承诺、想把昨晚聊了一半的那个会话继续聊下去，都得在文件管理器里翻一堆看不懂的文件名、手动打开一个又一个去猜内容，十分钟内找不到就放弃。
- **与相邻模块的分界**：
  - "Chat Tab 本身、三栏布局、项目 / 会话列表、会话详情气泡、重命名、恢复到终端" 属于本模块
  - "搜索框、关键词匹配、搜索结果高亮与跳转" 属于 [M09 CHAT_SEARCH]
  - "自动归档、导出成 Markdown、删除后从归档恢复" 属于 [M10 CHAT_SYNC]
  - "恢复到终端之后新终端本身的行为" 属于 [M01 TERM_LIFECYCLE]

## 2. 目标用户与场景

### 主要用户画像

- **Claude Code / Codex 重度用户**：一天可能开 5-10 个会话，每个项目下半年累计几百个会话。经常想"前两天让 AI 帮我重构过那个函数，它当时的方案是什么来着？"——需要一个能按项目、按时间迅速翻回到那个会话的地方。
- **多项目并发的开发者**：同时维护 3-8 个仓库，每个仓库都跟 Claude Code 聊过。想清晰看到"这是哪个项目的会话"，而不是所有对话糊在一起。
- **新手**：第一次点开 Chat Tab，只想先看看这个界面长什么样、有没有自己以前的聊天。希望能一眼看懂左边是什么、中间是什么、右边是什么。

### Top3 使用场景

**场景 1 — 翻回昨天那段对话**：用户今天上班打开 Muxvo 点 Chat Tab，默认看到所有项目会话按时间倒序。扫一眼中栏，第一张卡片就是昨晚聊到半夜那个，点一下右边铺开全部对话，滚到底部看到自己最后说的话和 AI 最后的答复，心里有底。

**场景 2 — 按项目收敛**：用户同时维护 muxvo 和 side-project 两个仓库，只想看 muxvo 的会话。点左栏"muxvo"那行，中栏立刻只剩 muxvo 相关的。找到三天前的权限修复会话点开，右栏里还能看到当时 AI 贴的代码块，点代码块右上角复制按钮，代码进剪贴板。

**场景 3 — 把历史会话继续聊下去**：用户一周前聊到一半被打断，现在想接着聊。在 Chat Tab 找到那个会话打开详情，点右上角"继续聊天"按钮，Muxvo 跳回 Terminal Tab 新开一个终端，上下文自动恢复，用户继续敲下一条 prompt 就像从未离开过。

### 使用频率

日常中高频。重度用户每天进 Chat Tab 3-10 次，每次停留 30 秒到几分钟。"恢复到终端"是偶尔但关键的操作，一周 2-5 次，每一次都必须稳。

## 5. 详细需求条目

### REQ-CHAT_BROWSE-001 Chat 一级 Tab 入口

- **触发**：用户点顶部一级导航的"Chat"项（Muxvo 已启动）。
- **流程**：Chat 导航项变选中 → 主区切到 Chat 页面 → 三栏立即显现 → 左栏和中栏开始加载数据，右栏显示空态。
- **反馈**：导航项高亮；从上一个 Tab 平滑过渡。
- **结束**：用户停留在 Chat 页面。
- **异常**：没有任何 CLI 使用痕迹 → 左中两栏分别显示友好空态；数据读取出问题 → 列表显示"暂无会话记录"，不崩溃。

### REQ-CHAT_BROWSE-002 三栏固定布局

- **触发**：进入 Chat 页面自动生效。
- **流程**：用户看到左栏（项目列表）、中栏（会话列表）、右栏（会话详情）横向并列。
- **反馈**：左栏约 220 宽、中栏约 340 宽、右栏占剩余宽度；三栏间有细分隔线。
- **结束**：三栏稳定并列，可直接操作任一栏。
- **异常**：窗口过窄时不破版，内容按需压缩。

### REQ-CHAT_BROWSE-003 左栏项目列表

- **触发**：进入 Chat 页面自动加载。
- **流程**：左栏顶部显示"项目"标题 → 下方列出"全部项目"入口 + 按项目的行 → 每行：彩色圆点 + 项目短名 + 该项目的聊天体量数字。
- **反馈**：悬停行有高亮；悬停显示完整路径 tooltip。
- **结束**：用户可点任一行筛选。
- **异常**：项目过多时左栏内部可滚动。

### REQ-CHAT_BROWSE-004 "全部项目"选项默认选中

- **触发**：首次进入 Chat 页面。
- **流程**：左栏顶部"全部项目"行处于高亮 → 中栏显示跨所有项目的会话。
- **反馈**："全部项目"行选中色；圆点使用主色。
- **结束**：用户默认在跨项目视图下。
- **异常**：切到某项目再切回效果一致。

### REQ-CHAT_BROWSE-005 左栏圆点颜色稳定

- **触发**：每次打开 Chat 页面自动渲染。
- **流程**：同一个项目在每一次打开时都显示相同颜色的圆点。
- **反馈**：形成视觉记忆——"红圆点=muxvo、绿圆点=side-project"。
- **结束**：项目有稳定的颜色身份。
- **异常**：新项目首次出现得到一个稳定的新颜色。

### REQ-CHAT_BROWSE-006 中栏会话卡片

- **触发**：左栏选择"全部项目"或某项目后自动展示。
- **流程**：中栏顶部显示"会话 (N)"标题 → 下方列出卡片 → 每张卡片三层：标题+时间行、预览行、底部徽标行。
- **反馈**：卡片有圆角、分隔、悬停高亮；选中卡片有明显边框。
- **结束**：用户可点任一卡片进入详情。
- **异常**：标题过长自动截断加省略号。

### REQ-CHAT_BROWSE-007 中栏按时间倒序

- **触发**：进入或切换项目后自动排序。
- **流程**：最近活动的会话排在最上方，最早的在最下方。
- **反馈**：用户第一眼看到的就是最新的那个会话。
- **结束**：排序稳定，不因切项目而打乱。
- **异常**：两条时间完全相同的会话按稳定顺序显示，不跳动。

### REQ-CHAT_BROWSE-008 智能时间格式

- **触发**：每张卡片渲染时自动格式化。
- **流程**：今天 → "今天 HH:MM"；昨天 → "昨天 HH:MM"；更早 → "MM-DD HH:MM"。
- **反馈**：时间靠卡片右上角，灰色小字。
- **结束**：用户一眼知道新旧。
- **异常**：跨年的会话仍只显示 MM-DD HH:MM，同一项目内一般不混到去年。

### REQ-CHAT_BROWSE-009 多源来源徽标

- **触发**：会话卡片渲染时自动显示。
- **流程**：Claude Code → CC 徽标；Codex → CX 徽标；Gemini → GM 徽标。
- **反馈**：小胶囊位于卡片底部徽标行最左侧，不同底色区分。
- **结束**：同列混合时可快速区分。
- **异常**：未知来源不显示徽标，不报错。

### REQ-CHAT_BROWSE-010 全部项目视图下显示所属项目

- **触发**：用户处于"全部项目"视图。
- **流程**：每张卡片底部徽标行额外出现一个项目名徽标（该会话所属项目的短名）。
- **反馈**：在混合列表中方便识别项目归属。
- **结束**：切到具体项目视图时该项目徽标自动隐藏避免重复。
- **异常**：项目名过长时徽标截断。

### REQ-CHAT_BROWSE-011 关键词自动打标签

- **触发**：卡片渲染时分析标题文本。
- **流程**：feat/feature → 绿 feat；fix/bug → 红 fix；refactor → 蓝 refactor；plan → 紫 plan。
- **反馈**：小胶囊标签出现在卡片底部徽标行。
- **结束**：用户可凭颜色快速扫视同类会话。
- **异常**：未命中任何关键词时无标签显示。

### REQ-CHAT_BROWSE-012 选中会话加载详情

- **触发**：用户点中栏任一卡片（卡片非重命名中）。
- **流程**：卡片变选中样式 → 右栏进入加载骨架 → 500 毫秒内渲染完整消息流 → 默认滚动到最后一条。
- **反馈**：加载时右栏出现 6 条骨架气泡，加载完后气泡按时间顺序铺开。
- **结束**：用户可浏览、复制、滚动该会话。
- **异常**：加载失败 → 右栏显示"暂无内容"提示。

### REQ-CHAT_BROWSE-013 右栏消息气泡布局

- **触发**：加载完详情后渲染。
- **流程**：用户消息靠右、主色底；AI 消息靠左、浅色底；系统消息单独灰色样式。
- **反馈**：每个气泡顶部有角色标签"YOU / CLAUDE / CODEX / GEMINI / SYSTEM"。
- **结束**：用户一眼分清谁说了什么。
- **异常**：未知角色退化为 SYSTEM 样式，不崩溃。

### REQ-CHAT_BROWSE-014 AI 消息的 Markdown 渲染

- **触发**：AI 气泡渲染时。
- **流程**：加粗 / 斜体 / 列表 / 链接 / 标题按 Markdown 渲染；代码围栏成为代码块；链接可点击。
- **反馈**：排版接近 GitHub 风格。
- **结束**：阅读体验与"浏览器看 Markdown"一致。
- **异常**：异常 Markdown 退化为纯文本展示，不破坏布局。

### REQ-CHAT_BROWSE-015 代码块复制按钮

- **触发**：代码块右上角显示复制图标。
- **流程**：用户点复制 → 代码原文进入剪贴板。
- **反馈**：按钮轻微按下反馈动效。
- **结束**：用户可在其他地方粘贴。
- **异常**：代码块为空时按钮无效但不报错。

### REQ-CHAT_BROWSE-016 工具调用默认折叠

- **触发**：AI 消息里包含工具调用或工具结果块时自动渲染。
- **流程**：工具调用块默认折叠（蓝色左边框、"Tool Call: 名称"标题、折叠箭头）；工具结果块默认折叠（绿色左边框、"Tool Result"标题）；点标题展开 / 再点折叠。
- **反馈**：折叠时气泡紧凑，展开时清楚看到输入/输出。
- **结束**：用户可在需要时钻入细节。
- **异常**：工具输入输出为空 → 展开后显示友好占位。

### REQ-CHAT_BROWSE-017 消息时间戳

- **触发**：每个气泡渲染时自动附带。
- **流程**：每个气泡右下角显示该条消息的绝对时间（时分秒）。
- **反馈**：小灰字，不抢主内容。
- **结束**：用户可看出消息之间的时间间隔。
- **异常**：时间异常 → 显示为空而不是报错。

### REQ-CHAT_BROWSE-018 长会话懒加载

- **触发**：打开某个消息较多的会话详情时。
- **流程**：首次只渲染最近 50 条 → 用户向上滚到顶部 → 顶部出现加载指示 → 追加前 50 条更早的 → 全部加载完顶部显示"— 已加载全部 —"。
- **反馈**：顶部有小旋转指示；加载流畅不打断滚动节奏。
- **结束**：用户可一直向上翻到会话最开头。
- **异常**：加载失败时顶部提示"加载失败"并保留已加载内容。

### REQ-CHAT_BROWSE-019 长会话顺滑滚动

- **触发**：用户在右栏用滚轮或触控板滚动。
- **流程**：即使总消息数达几百条，滚动保持流畅；只渲染可视区域附近的气泡。
- **反馈**：无掉帧、无白屏。
- **结束**：用户心流不被打断。
- **异常**：极大会话（超 5000 条）时滚动可能略有延迟但不卡死。

### REQ-CHAT_BROWSE-020 右栏空态提示

- **触发**：未选中任何卡片时。
- **流程**：右栏中央显示"选择一个会话查看详情"灰色提示文案。
- **反馈**：不是空白一片，有明确指引。
- **结束**：用户下一步会去点一张卡片。
- **异常**：选中后又切项目清空时回到此态。

### REQ-CHAT_BROWSE-021 点项目切换过滤

- **触发**：用户点左栏某项目或"全部项目"。
- **流程**：左栏该项高亮 → 中栏立即更新为该范围的会话列表 → 计数标题刷新。
- **反馈**：无延迟感，点一下就变。
- **结束**：用户处于该项目的聚焦视图。
- **异常**：项目下无会话 → 中栏显示"暂无会话记录"。

### REQ-CHAT_BROWSE-022 切项目清空右栏

- **触发**：左栏项目切换时联动。
- **流程**：用户切项目 → 之前在右栏显示的会话详情被清空 → 右栏回到"选择一个会话查看详情"。
- **反馈**：防止用户误以为新项目里也有那条会话。
- **结束**：用户重新从中栏选。
- **异常**：切到"全部项目"同样清空，保持一致。

### REQ-CHAT_BROWSE-023 右键菜单

- **触发**：用户在会话卡片上按鼠标右键（卡片未在重命名）。
- **流程**：鼠标位置弹出菜单，至少包含"重命名""导出""删除"三项 → 用户选一项触发对应动作。
- **反馈**：原生风格菜单，位置贴近鼠标。
- **结束**：菜单收起，选中项的动作被执行。
- **异常**：点菜单外部或按 Esc → 菜单关闭，不执行任何动作。

### REQ-CHAT_BROWSE-024 会话重命名

- **触发**：右键菜单选"重命名"。
- **流程**：卡片标题变输入框并预填当前标题全选 → 用户输入新名 → Enter 或失焦保存 / Esc 取消。
- **反馈**：输入框自动聚焦；保存后卡片立即显示新名字。
- **结束**：卡片标题变为用户自定义值。
- **异常**：输入空字符串并回车 → 恢复为默认标题，不保存空值。

### REQ-CHAT_BROWSE-025 重命名持久化

- **触发**：重命名确认后自动生效。
- **流程**：关闭并重新打开 Chat Tab，新名字仍在。
- **反馈**：跨会话、跨重启都保留。
- **结束**：整理成果不会丢失。
- **异常**：保存失败 → 卡片恢复旧名字，短暂提示"保存失败"。

### REQ-CHAT_BROWSE-026 删除会话

- **触发**：右键菜单选"删除"。
- **流程**：弹出确认对话框"确定删除此聊天记录？删除后无法恢复。" → 用户确认 → 卡片从中栏消失 → 若删的正是当前选中的，右栏清空回到空态。
- **反馈**：确认对话框；删除后列表自动收紧。
- **结束**：会话在 Chat Tab 中不再出现。
- **异常**：删除失败 → 保留原卡片并提示"删除失败"。

### REQ-CHAT_BROWSE-027 恢复会话到终端

- **触发**：用户点右栏顶部的"继续聊天"按钮。
- **前置**：当前会话来源是 Claude Code 或 Codex，且能推断出工作目录。
- **流程**：按下按钮 → Muxvo 跳回 Terminal Tab → 新开一个终端，位置正确、上下文已恢复到该会话；若会话有自定义标题，新终端的标签也继承。
- **反馈**：按钮按下反馈；Tab 切换；新终端在几秒内可见可输入。
- **结束**：用户回到 Terminal Tab，可立刻继续对话。
- **异常**：无法确定工作目录 → 按钮被隐藏；恢复过程出错 → 提示"无法恢复会话"。
- **相关**：[M01-REQ-001]。

### REQ-CHAT_BROWSE-028 无法恢复的会话禁用按钮

- **触发**：详情加载完成后判断。
- **流程**：若来源不是 Claude Code / Codex，或推断不出工作目录 → "继续聊天"按钮不显示。
- **反馈**：看不到按钮，不会产生"点了没反应"的困惑。
- **结束**：用户只能浏览不能恢复。
- **异常**：短暂加载时按钮可能延后出现，不闪烁。

### REQ-CHAT_BROWSE-029 实时追加新消息

- **触发**：当前打开的会话在后台被继续写入。
- **流程**：外部写入被检测到 → 右栏自动追加新消息 → 若用户没在向上翻阅，自动滚动到最新位置。
- **反馈**：新气泡从下方平滑出现。
- **结束**：右栏永远显示最新状态。
- **异常**：用户正在向上翻阅历史 → 不强制拉到底部，避免打断阅读。

### REQ-CHAT_BROWSE-030 加载骨架

- **触发**：首次打开 Chat Tab 或切项目等待数据时。
- **流程**：左栏 5 条骨架行；中栏 8 张骨架卡片；右栏保持空态不骨架。
- **反馈**：占位条有微动画，暗示"正在加载"。
- **结束**：数据到达后骨架被真实内容替换。
- **异常**：长时间加载不完 → 保持骨架直到结果（无超时崩溃）。

### REQ-CHAT_BROWSE-031 空态：无项目

- **触发**：本地没有任何 CLI 项目数据。
- **流程**：左栏只显示"全部项目"入口，下方为空；中栏显示"暂无会话记录"；右栏显示"选择一个会话查看详情"。
- **反馈**：不是错误，而是友好的空白引导。
- **结束**：用户明白"还没开始聊"。
- **异常**：未来首次使用某 CLI 后下次打开即可看到数据。

### REQ-CHAT_BROWSE-032 空态：项目下无会话

- **触发**：左栏选中的项目下没有任何会话。
- **流程**：中栏显示"暂无会话记录"占位文案。
- **反馈**：不误导成错误。
- **结束**：用户可切回"全部项目"或选另一个项目。
- **异常**：列表被过滤到空（搜索场景）由 [M09 CHAT_SEARCH] 处理。

### REQ-CHAT_BROWSE-033 首次归档说明横幅

- **触发**：用户首次进入 Chat Tab（之前从未关闭过该横幅）。
- **流程**：页面顶部出现横幅，说明 Muxvo 会为聊天记录做自动备份；横幅右侧提供"自动归档：开启 / 关闭"开关和关闭按钮；用户点关闭 → 横幅收起并不再主动出现。
- **反馈**：柔和的提示色，不抢镜。
- **结束**：用户对"我的聊天不会丢"有基本信心。
- **异常**：开关的详细行为属于 [M10 CHAT_SYNC]。

## 7. 界面规格

### 7.1 页面/面板清单

| 名称 | 作用 | 进入方式 | 退出方式 |
|---|---|---|---|
| Chat 页面 | 聊天历史浏览主页，承载三栏 | 点顶部 Chat 一级 Tab | 切到其他一级 Tab |
| 归档说明横幅 | 首次访问时的友好提示 | 首次进入 Chat 页面自动显现 | 点关闭 × 按钮 |
| 会话右键菜单 | 对单条会话的操作入口 | 在卡片上点鼠标右键 | 点菜单外、按 Esc、选完一项 |
| 删除确认对话框 | 二次确认会话删除 | 右键菜单选"删除" | 点"取消"或点"确定" |
| 重命名内联输入框 | 修改会话标题 | 右键菜单选"重命名" | 按 Enter / 失焦保存，按 Esc 取消 |

### 7.2 各页关键区域

**顶栏**：应用一级导航（由 M15 提供），在 Chat 页面无额外顶栏。

**左栏（项目列表）**：顶部"项目"分组标题 → "全部项目"固定入口（主色圆点 + 全部体量数字）→ 下方按项目滚动列表，每项"彩色圆点 + 项目短名 + 体量数字"，悬停显示完整路径 tooltip，选中项有高亮背景。

**中栏（会话卡片列表）**：顶部"会话 (N)"计数标题 → 其下搜索框（由 [M09 CHAT_SEARCH] 提供）占一行 → 可滚动的会话卡片列表。每张卡片三行：标题行（标题 + 智能时间）、预览行（2 行截断）、底部徽标行（来源徽标 CC / CX / GM + 项目徽标 + 关键词标签 + 体量数字）。卡片悬停 / 选中高亮；滚到底部自动加载更多。

**右栏（会话详情）**：顶部（可选）"继续聊天"按钮条，仅在能恢复时出现 → 主体气泡流从上到下：用户气泡靠右主色底、AI 气泡靠左浅色底（Markdown 渲染）、工具调用 / 工具结果块默认折叠带彩色左边框、每个气泡底部有时间戳、每个代码块右上角有复制按钮；滚动时顶部出现"加载更早"指示或"— 已加载全部 —"；未选中时中央显示"选择一个会话查看详情"。

**底栏**：无。**浮层**：右键菜单、删除确认对话框、顶部归档说明横幅。

### 7.3 五态规格（Chat 页面）

| 状态 | 用户看到什么 | 可做的动作 |
|---|---|---|
| **空态** | 左栏只有"全部项目"一行；中栏显示"暂无会话记录"；右栏显示"选择一个会话查看详情" | 先去 Terminal Tab 开始聊，再回来 |
| **加载态** | 左栏显示 5 条骨架行；中栏显示 8 张骨架卡片；右栏正常空态 | 等待数据就绪 |
| **正常态** | 三栏齐备：左栏项目 / 中栏会话 / 右栏详情或空态 | 点项目、点卡片、右键卡片、点"继续聊天" |
| **错误态** | 数据读取出错时中栏显示"暂无会话记录"（不抛出令人恐慌的错误框），用户可切项目重试 | 切项目、重新进入 Chat Tab |
| **受限态** | 当前无受限态（不涉及登录/权限） | — |

### 7.4 文案示例

> 空态（中栏）："暂无会话记录"
> 空态（右栏）："选择一个会话查看详情"
> 长会话完结提示："— 已加载全部 —"
> 删除确认："确定删除此聊天记录？删除后无法恢复。"
> 右键菜单项："重命名" / "导出" / "删除"
> 恢复按钮："继续聊天"
> 归档横幅开关："自动归档：开启" / "自动归档：关闭"

## 8. 状态与交互规则

### 8.1 可见状态清单

- 用户看到 **"还在加载"**：某一栏展示骨架占位
- 用户看到 **"没有内容"**：文案为"暂无会话记录"或"选择一个会话查看详情"
- 用户看到 **"有内容"**：列表 / 气泡正常渲染
- 用户看到 **"当前选中"**：左栏项目行高亮 / 中栏卡片高亮
- 用户看到 **"正在重命名"**：卡片标题变为输入框
- 用户看到 **"可以继续聊天"**：右栏顶部出现按钮条
- 用户看到 **"不能继续聊天"**：右栏顶部没有按钮条

### 8.2 状态切换触发

- 用户进入 Chat Tab → 看到骨架 → 数据到达后看到正常内容
- 用户点项目 → 中栏变为该项目的会话列表，右栏清空为"选择一个会话查看详情"
- 用户点卡片 → 卡片高亮 → 右栏从空态或别的会话切到该会话
- 用户右键 → 出现菜单；选"重命名" → 卡片标题变输入框
- 用户按 Enter 或输入框失焦 → 卡片显示新标题
- 用户点"继续聊天" → Muxvo 切到 Terminal Tab，新终端出现
- 用户删除当前选中的会话 → 右栏回到空态

### 8.3 快捷键与手势

| 按键/手势 | 作用 | 前置条件 |
|---|---|---|
| 左键点项目行 | 切换项目筛选 | 在 Chat 页面 |
| 左键点卡片 | 打开该会话详情 | 非重命名中 |
| 右键点卡片 | 弹出卡片菜单 | 非重命名中 |
| Enter | 确认重命名 | 处于重命名输入框 |
| Esc | 取消重命名 | 处于重命名输入框 |
| 鼠标滚轮 / 触控板 | 在中栏和右栏内滚动 | — |

（注：打开 / 关闭 Chat Tab 的快捷键由 [M15 APP_RELIABILITY] 的全局导航定义。搜索相关快捷键归 [M09 CHAT_SEARCH]。）

### 8.4 多窗口/多标签行为

- Muxvo 当前通常只有一个主窗口；若未来有多窗口，每个窗口的 Chat 页面各自维护所选项目、所选会话、滚动位置；重命名与删除的结果对所有窗口最终一致。
- Chat 页面本身只有一个页签，不允许同时打开多个 Chat 页面。

## 9. 边界、限制与异常

- **数量限制**：
  - 中栏会话卡片列表首次渲染 50 条，滚动到底自动追加下一批 50 条，直到全部列出
  - 右栏消息气泡首次渲染最近 50 条，滚动到顶自动追加前 50 条
  - 单栏滚动范围内无绝对上限，性能上保证几百条级别顺滑
- **明确不支持**：
  - 本版不支持跨项目拖拽 / 合并会话
  - 本版不支持多选卡片批量操作
  - 本版不支持按时间以外的字段排序（如按消息数、按体量）
  - 本版不支持对单条消息的内联编辑
  - 本版不支持在 Chat 页面里直接给 AI 发送新消息（发送能力属于 Terminal + Editor）
- **错误提示文案**：
  - 数据读取异常 → 列表显示"暂无会话记录"占位，不弹红色错误
  - 重命名保存失败 → 卡片恢复旧名字并 toast 级提示"保存失败"
  - 删除失败 → 卡片保留并提示"删除失败"
  - 恢复到终端失败 → 提示"无法恢复会话"并保留在 Chat Tab
- **数据丢失风险**：
  - 用户执行"删除"是不可逆的（确认对话框已明示）
  - 自定义标题若未成功保存可能丢失用户输入 → 保存失败时输入框不关闭，让用户重试
  - 自动归档与真实数据的一致性保障属于 [M10 CHAT_SYNC]

## 10. 明确不做的事（Out of Scope）

- **不做搜索**：整条搜索能力（搜索框、匹配、高亮、跨会话跳转）归 [M09 CHAT_SEARCH]，本模块只负责把搜索框的位置预留在中栏顶部。
- **不做归档与导出逻辑**：自动归档、手动导出 Markdown、从归档恢复已删除的会话 → [M10 CHAT_SYNC]。
- **不做 Chat 页面内的直接发送**：本模块是"浏览器"不是"编辑器"；发送必须通过 Terminal Tab + Editor。
- **不做可调栏宽**：当前版本三栏宽度固定，未来若有强需求再考虑。
- **不做收藏夹 / 重要标记 / 文件夹 / 项目手动分组**：本版不引入多层级组织；左栏保持扁平。
- **不做跨设备同步**：Chat Tab 只展示本机的历史，不做云同步。
- **不做多选批量操作 / 会话合并**：删除、重命名、导出都只对单个会话生效；无法把两个半截对话合成一个。
- **不做富交互时间轴**：不提供日历视图或按月 / 按周过滤；默认按时间倒序足够。
