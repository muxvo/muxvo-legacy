# A1. 快捷键与手势汇总

> 本附录汇总 15 个模块中所有用户可用的快捷键和手势。每条都给出前置条件和所属模块。

---

## 1. 全局快捷键（任何界面都生效）

| 快捷键 | 作用 | 所属模块 |
|---|---|---|
| `⌘T` / `Ctrl+T` | 创建新终端 | [M01-REQ-TERM_LIFECYCLE] |
| `⌘+` / `Ctrl++` | 放大界面（+10%） | [M14-REQ-ONBOARD_PREFS-014] |
| `⌘-` / `Ctrl+-` | 缩小界面（-10%） | [M14-REQ-ONBOARD_PREFS-014] |
| `⌘0` / `Ctrl+0` | 重置缩放为 100% | [M14-REQ-ONBOARD_PREFS-014] |
| `⌘←` / `Ctrl+←` | 光标移到行首 | 通用文本编辑 |
| `⌘→` / `Ctrl+→` | 光标移到行尾 | 通用文本编辑 |

---

## 10. 原则

1. **一致性**：相同作用在不同界面用相同快捷键（例：`Esc` 永远是"返回/取消"）
2. **不冲突**：富编辑器的 `Ctrl+C` / `Ctrl+Z` / `Ctrl+D` 透传给终端，避免和终端内的命令断行为冲突
3. **可发现**：所有按钮都有 tooltip 显示对应快捷键
4. **可替代**：所有快捷键都有鼠标操作等价入口，避免强依赖键盘
