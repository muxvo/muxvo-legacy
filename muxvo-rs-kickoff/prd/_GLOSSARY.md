# 全局术语表

> 本文件定义 PRD 全文使用的产品术语。禁止在模块内重新定义，只能引用。

---

## 核心产品术语

| 术语 | 定义 |
|---|---|
| **Muxvo** | 本产品名。一个可管理多个 AI CLI 工具（Claude Code / Codex / Gemini CLI）的桌面工作台 |
| **终端** | 运行 CLI 工具的独立面板。每个终端有自己的工作目录、运行状态、输入输出区 |
| **工作区** | 用户当前的终端布局 + 所有终端的状态快照。可保存和恢复（最多 10 个） |
| **项目** | 一组在相同目录下的 AI 会话集合。按 cwd 自动归类 |
| **会话** | 用户与 AI CLI 的一次对话记录，包含历史消息、输入输出 |
| **Claude Code** | Claude 官方 CLI，简称 CC。Muxvo 的主要支持对象 |
| **Codex** | OpenAI 的 AI CLI，Muxvo 的第二支持对象 |
| **CLI 工具** | 命令行形态的 AI 对话工具。本 PRD 中特指上述几类 |

---

## Claude 配置术语

以下是 Claude Code 本身的概念，Muxvo 提供可视化管理。

| 术语 | 定义 |
|---|---|
| **Skill** | 给 Claude 添加能力的模块，包含 SKILL.md、references、scripts 等文件 |
| **MCP（Model Context Protocol）** | 外部服务与 Claude 对话的标准协议，用户可添加 MCP Server |
| **Hook** | 在 Claude 执行过程中的特定时机触发的用户脚本 |
| **Plugin** | 第三方扩展（含 Skills + MCP + Hooks 的打包集合） |

> 注：以上都是 Claude 已有的用户侧概念，**不是 Muxvo 的技术实现**。描述时用"用户看到/管理 X 类配置"，不写底层协议。

## 界面术语

| 术语 | 定义 |
|---|---|
| **菜单栏** | 主窗口顶部的 36px 高导航区，含 6 个一级 Tab |
| **一级 Tab** | 菜单栏中的主导航按钮：Terminals / Skills / MCP / Hooks / Plugins / Chat |
| **面板（Panel）** | 一级 Tab 对应的全屏浮层或工作区 |
| **Tile** | 终端网格中的一个单元（一个终端的显示框） |
| **平铺模式（Tiling）** | 多个终端并列显示的网格布局 |
| **聚焦模式（Focused）** | 单个终端全屏显示、其他缩略图在侧栏的布局 |
| **临时视图（Temp View / FTV）** | 三栏浮层：左文件树 / 中预览 / 右终端栏 |
| **文件面板** | 侧滑式的工作区文件浏览器 |
| **等待输入通知** | 终端需要用户输入时的视觉提示（红点、徽标、Dock Badge） |
| **状态点** | Tile 左上角或右上角的小圆点，表示终端运行状态 |

## 交互术语

| 术语 | 定义 |
|---|---|
| **前台进程** | 当前占据终端 I/O 的进程（决定关闭是否需确认） |
| **等待输入** | 终端空闲但有未完成的对话状态（如 Claude 提了问但用户没答） |
| **归档同步** | 把 Claude 原生会话文件镜像到 Muxvo 本地，便于浏览搜索 |
| **多源** | 同时支持多个 CLI 工具（CC / Codex）作为数据源 |
| **cwd** | Current Working Directory，终端的当前工作目录 |

## 用户画像

| 画像 | 定义 |
|---|---|
| **CLI 重度用户** | 每天用 Claude Code 工作 4 小时以上，同时管理多个终端和项目 |
| **项目切换者** | 需要在多个代码仓库之间快速切换的工程师 |
| **Skill 作者** | 自己开发 Claude Skill 并调试的用户 |
| **新手** | 第一次使用 Muxvo 或第一次用 AI CLI 的用户 |
